# Tonspuren von Florian Homm

Jede Erklärung in der App kann mit Florians Stimme abgespielt werden. Legen Sie die Aufnahme als MP3 (oder M4A) mit genau diesem Dateinamen in diesen Ordner (`public/audio/`). Die App erkennt neue Dateien automatisch; fehlt eine Datei, liest die Browser-Stimme den Text vor.

Empfehlung: Mono, 44,1 kHz, 96–128 kbit/s, Lautheit etwa −16 LUFS, kurze Stille am Anfang und Ende entfernen.

| Datei | Text (Entwurf, Florian darf frei formulieren) |
|---|---|
| `welcome.mp3` | Willkommen in meiner Investment Arena. Sie haben 100.000 Euro Spielgeld. Hier dürfen Sie die Fehler machen, die im echten Leben ein Vermögen kosten. Tippen Sie auf einen Wert und probieren Sie es aus. |
| `welcomePro.mp3` | Sie kennen das Spiel. Hier haben Sie Optionen, Hebel bis zwanzigfach und echte Kurse. Zeigen Sie der Community, wie man auch in fallenden Märkten verdient. |
| `long.mp3` | Long heißt: Sie setzen auf steigende Kurse. Ihr Risiko ist der Einsatz, Ihre Chance ist nach oben offen. So handeln die meisten Anleger – und genau deshalb lohnt es sich, auch die andere Seite zu verstehen. |
| `short.mp3` | Short heißt: Sie setzen auf fallende Kurse. Sie verkaufen etwas, das Sie sich geliehen haben, und kaufen es später hoffentlich billiger zurück. Vorsicht: Steigt der Kurs, ist Ihr Verlust theoretisch unbegrenzt. |
| `stock.mp3` | Direkt investiert: kein Hebel, kein Verfallstag. Klingt langweilig – aber so überlebt man an der Börse. Beim Short leihen Sie sich den Wert und zahlen dafür eine kleine Leihgebühr. |
| `crypto.mp3` | Krypto handelt rund um die Uhr und schwankt oft fünfmal so stark wie eine Aktie. Das macht Spaß, solange die Position klein ist. Setzen Sie hier nur, was Sie auch ganz verlieren könnten. |
| `lev.mp3` | Ein Hebel vervielfacht Gewinn und Verlust. Bei Hebel fünf reicht ein Minus von zwanzig Prozent, und Ihr Einsatz ist weg. Ein Hebel ist kein Turbo, sondern ein Messer. Und er kostet jeden Tag Finanzierungszinsen. |
| `call.mp3` | Ein Call ist das Recht, zu einem festen Preis zu kaufen. Er gewinnt, wenn der Kurs deutlich über den Basispreis steigt. Mehr als die Prämie können Sie nicht verlieren – aber die Zeit arbeitet gegen Sie, jeden einzelnen Tag. |
| `put.mp3` | Ein Put ist das Recht, zu einem festen Preis zu verkaufen. Er gewinnt, wenn der Kurs fällt. Profis nutzen Puts vor allem als Versicherung für ihr Depot. Ihr maximaler Verlust ist die gezahlte Prämie. |
| `otm.mp3` | Je weiter aus dem Geld, desto billiger die Option – und desto unwahrscheinlicher, dass sie sich lohnt. Billig ist nicht dasselbe wie günstig. |
| `size.mp3` | Setzen Sie nie mehr als fünf bis zehn Prozent Ihres Depots auf eine einzige Idee. Viele, die pleitegegangen sind, lagen gar nicht falsch. Sie waren nur zu groß positioniert. |
| `stop.mp3` | Ein Stop-Loss ist Ihre Notbremse. Legen Sie fest, wie viel Sie verlieren wollen, bevor Sie kaufen – nicht danach, wenn die Gefühle mitreden. |
| `live.mp3` | Ihre Position läuft jetzt mit dem echten Markt. Alle in der Arena sehen dieselben Kurse. Schauen Sie morgen wieder rein – und bei Optionen denken Sie daran: Die Zeit frisst jeden Tag ein Stück vom Wert. |
| `margin.mp3` | Nachschussalarm! Eine Hebelposition hat drei Viertel ihres Einsatzes verloren. Merken Sie sich dieses Gefühl. Genau hier treffen die meisten ihre schlechtesten Entscheidungen. |
| `knock.mp3` | Knock-out. Die Position ist ausgelöscht. Bei einem Hebel ist das kein Pech, sondern Mathematik. |
| `profit.mp3` | Gewinne mitzunehmen ist keine Schande. Niemand ist je pleitegegangen, weil er zu früh Gewinne realisiert hat. |
| `loss.mp3` | Ein Verlust ist Lehrgeld – solange er klein bleibt. Fragen Sie sich ehrlich: War das eine Idee oder eine Hoffnung? |
| `insider.mp3` | Insider verkaufen aus hundert Gründen: Steuern, Hauskauf, Scheidung. Aber sie kaufen nur aus einem einzigen Grund. Ein Insiderkauf mit eigenem Geld ist das stärkste Signal, das ich kenne. Verkäufe dagegen nehme ich ernst, wenn viele gleichzeitig verkaufen. |
| `analyst.mp3` | Wenn alle Analysten Kaufen sagen, frage ich mich zuerst: Wer soll eigentlich noch kaufen? Der Konsens ist meistens schon im Kurs. Interessant wird es, wenn die Zahlen anders aussehen als die Meinung. |
| `earnings.mp3` | Quartalszahlen sind der Moment der Wahrheit. Entscheidend ist nicht, ob ein Unternehmen Gewinn macht, sondern ob es die Erwartungen schlägt. Vor den Zahlen eine große Position aufzubauen, ist eher Zocken als Investieren. |
| `volume.mp3` | Ungewöhnlich hohes Volumen heißt: Irgendjemand weiß etwas oder glaubt, etwas zu wissen. Das ist kein Kaufsignal, sondern ein Grund, genauer hinzuschauen. |
| `radar.mp3` | Das ist mein Radar. Hier sehen Sie, was Insider tun, was Analysten erwarten und wo es bald Zahlen gibt. Profis schauen zuerst hierhin und erst danach auf den Kurs. |
| `fundInvest.mp3` | Bevor Sie Geld in einen Fonds stecken, schauen Sie nicht nur auf die Rendite. Schauen Sie, wie der Manager denkt. Eine gute Strategie mit Pech ist mir lieber als eine schlechte mit Glück. |
| `fundCreate.mp3` | Ein guter Fonds ist kein Sammelsurium von Lieblingsaktien. Er hat eine klare Idee. Streuen Sie über mehrere Werte, setzen Sie keinem Einzelwert mehr als ein Viertel und denken Sie an eine Absicherung auf der Short-Seite. |
| `fundIntro.mp3` | Hier zeigt die Community, was sie kann. Jeder kann Fondsmanager werden. Die Besten stehen oben, und alle sehen, wer wirklich etwas vom Geschäft versteht. |
| `account.mp3` | Ihr Spielstand wird auf dem Server gespeichert. Sie können sich auf jedem Gerät anmelden und dort weitermachen. |
| `empty.mp3` | Noch keine Positionen. Ein guter Trader wartet auf die richtige Gelegenheit. Aber zum Lernen dürfen Sie hier ruhig einfach anfangen. |
| `arena.mp3` | Hier treten Sie gegen die Community an. Wichtig: Gewinnen kann man long wie short. Der Markt muss nicht steigen, damit Sie vorne liegen. |
| `profile.mp3` | Schauen Sie ruhig, was die Besten halten. Aber kopieren Sie nie blind. Verstehen Sie zuerst, warum jemand eine Position hat. |
